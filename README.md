# Automated_Pick_and_Place_System_using_4_DOF_Electropneumatic_Robotic_Arm

A mechatronics automation project involving the design, assembly,
control and validation of a 4-DOF electropneumatic robotic arm
for automated pick-and-place operations.

The system integrates pneumatic actuators, directional control
valves, solenoid valves, proximity sensors, limit switches,
relays and FESTO electropneumatic components to perform
controlled robotic motion and automated object handling.

## Project Highlights

- 4-DOF electropneumatic robotic arm
- Automated pick-and-place operation
- Pneumatic cylinder-based actuation
- FESTO electropneumatic components
- Solenoid and directional control valves
- Proximity sensors and limit switches
- Electrical control circuit development
- Mechanical assembly and hardware integration
- System testing and troubleshooting
- Functional validation
- Achieved 99% reported system results
